## 4. 世界观与双螺旋规则

### 4.1 继承设定

原初世界包含久世弦、林汐、镜湖及两套文明基础。第一次相位灾害中，灵矿与世界结构共振，产生两个稳定演化方向。灵矿共振是直接机制，灾害的最初触发者仍未定，不能自行认定父辈或主角就是幕后元凶。

| 概念 | 现行定义 | 可观察表现 |
|---|---|---|
| A／正螺旋 | 林汐侧，古代文明表现；保存、记忆、连接 | 古书、祭仪、刀术、石刻 |
| B／反螺旋 | 久世弦侧，现代文明表现；探索、变化、选择 | 手机、枪械、实验、照片 |
| 镜湖 | 两时间侧最接近处；不是任意穿越装置 | 共振、镜像景观、重复声音 |
| 灵矿 | 保存时间残留信息并放大共振的信息晶体 | 晶纹响应、武器共鸣、节点显现 |
| 残响 | 被覆盖状态留下的信息；不是灵魂 | 声音、文字、物品、行为、情感痕迹 |
| 潜行公式 | 跨侧信息共振的规律 | 一侧行动成为另一侧可读痕迹 |
| C0零点坍缩 | 强制消除两侧差异导致闭合 | 历史覆盖、记忆冲突、事件重复 |
| 神圣时间线 | 保留两侧完整性并建立稳定联系 | 莫比乌斯展开为螺旋，未来不再预先写定 |

### 4.2 现行解释

**古代不等于现代的单向过去。**A的行动可成为B的历史，B的行动也可成为A的历史。正反描述世界演化方向，不表示女主看见一切倒放；两侧人物都正常经历自己的生活。

局部观察像两条独立螺旋，沿全部因果连接追踪则回到自身，构成莫比乌斯闭环。一周目以久世弦所在的B反螺旋为主；二周目正式切换到林汐所在的A正螺旋，不是简单补充回忆。玩家用不同可探索空间、问题列表、战斗操作和人物关系重走同一因果环的另一面；古代遗迹中的电子警告、枪械零件成为B也在影响A的反证。

### 4.3 补拟：可实现的因果边界

仅对已有残响、灵矿节点或成对地点建立的关系生效；不能凭空指定世界任意事件。每个谜题登记「原因→连接→结果」，玩家切断具体连接而非抹除一个人的全部存在。

可变状态包括门路、攻击来源、证据版本、人物出场条件。结构节点包括第一次灾害、两侧形成、第一次坍缩；首轮只能改变局部条件，第二轮理解结构后解锁新的处理方法。固定节点由可检验限制表现，不靠无解释的按钮禁用。

改写在节点提交、离开场景或剧情切换时结算；一次只提交一个已验证方案。冲突方案先在古书／手机显示相互排斥的证据，不能让玩家无提示地把两个人物状态互相覆盖。

默认跨侧交流是文字、物品与残响，非全程语音通话。协作Boss期间共振增强，可交换有限的画面和行动信号，仍需玩家解读。


## 7. 香包、记忆与拍照

确认：香包是定情信物与情感／记忆载体；手机联系人与照片参与记忆变化。香包因果锚方向接受，具体机理与保留程度采用下列补拟。

香包最初装普通干花，不藏时间水晶。两人共同触碰过的事件使它关联两侧记录，偶尔保存改写差异。它不是能源，也不能证明所有人的全部过去。

| 载体 | 正常功能 | 改写后表现（补拟） | 边界 |
|---|---|---|---|
| 香包 | 定情、气味、触感 | 缝线与记忆不符，保留一小段残响 | 只提示差异，不直接给谜底 |
| 联系人 | 拨号、关系记录、生活弹窗 | 姓名、头像、最后联系时间变化或消失 | 多数记录遵循当前世界 |
| 手机相机 | 主动拍摄标识、现场、人物 | 普通照片可被改写；共振瞬间的照片留下局部重影 | 只有问题相关证据自动归档，避免无限相册管理 |
| 古书 | 抄录、拓印、问题整理 | 擦不尽的旧笔迹、与新行文字冲突 | 不是全知百科，不自动记下未见信息 |
| 手环／灯 | 显示局部共振或照明 | 颜色、脉冲、火焰朝向改变 | 是可选择的道具表现，不增设第三种超能力 |

记忆规则补拟：普通NPC与Boss默认遵循当前轮，不记得上轮玩家；两主角在共振后保留片段，不全知。玩家保留阅读知识，系统用「残留疑问」承接可操作目标。守环者记得多次灾害迹象，无法替玩家回忆所有选择。

首次重逢时香包不是融合许可；终局仍保留它的日常用途。让「记不住仍愿意做」落在可选行动、额外风险和新的结果上，不只一句台词。


## 22. 新文件并入与献灵规则补拟

### 22.1 新文件已明确的部分

久世弦黑发、高挑、理性；林汐银白长发、娇小但成熟强势，温柔坚定、不幼态。夏相识、秋默认在一起；冬因灵矿与献灵产生裂痕，林汐绕过久世弦独自献灵，他坚决反对。久世弦父母表面死于矿难，实际涉及雪山洞穴与封口事件。新增地点为青篁里、冥河、冥窟、灰港、白塔区。

新文件将观测枪械、断缘术及灵矿来源／献灵规则列为待完善；用户本次已明确的灵矿枪刀共振切因果优先。香包是情感锚，双因果锚仍属于可发展的具体解释。

### 22.2 献灵的v0.4补拟

将个人留下的一段可识别记忆／关系记录接入灵矿，作为暂时稳定异常联系的参照。以古代仪式语言称为献灵，现代可描述为个人记录被相位结构占用；不把残响改成真实灵魂。

一次献灵必须限定对象、范围和可见代价：某段共同经历难以被他人记住，相应文字与照片出现缺失。不能随意献出任意他人的存在，也不能靠路人献祭无成本解决全部异常。具体代价待用户选择Q11。

林汐发现眼前危机能用献灵暂时稳定，担心久世弦阻止，选择独自执行。她掌握局部依据并主动承担责任，但不知道强制统一方案的全局后果；久世弦的反对既有对她的关心，也有把自己的判断当唯一答案的缺陷。

玩家在第一轮先见到缺页、断联、笔迹和异常稳定的结果，第二轮从林汐视角经历决定与准备。同一事件两次呈现提供不同证据，不用整段重复对白解释。

献灵是维持联系的方法，枪刀是切断特定关系的方法，两者共享灵矿共振但用途不同。最终解法不要求林汐再次自我消除：双方识别强制覆盖连接，用三场协作中学到的方法保留联系。是否能恢复所有被占用记忆尚未承诺。

### 22.3 父母案件的证据链补拟

矿难公告→灰港运输记录→玄岳雪山洞穴封闭记录→第三研究所档案缺页。每项先证明一个具体矛盾，再推向下一地点；封口者身份、父母确切职务、死亡时间与第一次灾害的关联等待原始核心聊天，不提前编死谜底。
