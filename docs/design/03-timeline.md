## 12. 剧情四季与目标反转

### 夏：异常、失去与追问

叙事从冬篇冷开场开始：林舟从循环列车逃出，带着被水浸透的维修记录和科研资料抵达镜湖区。他只来得及完成交接，身体与记忆便因脱离循环而快速崩解。前10分钟以他的最后行动、资料中的异常和死亡／消失建立悬疑。片头后明确回到夏篇，展示久世弦与林汐相识；秋篇默认在一起。剪辑从冬到夏，世界内部关系顺序仍是夏→秋→冬。

### 秋：验证、帮助与错误确信

玩家证明另一侧有人回应，救人、开路、解决异常，开始相信「让两侧更接近就能结束一切」。每次确有善意成果，同时留下轻微不一致；不能事后宣称所有善行毫无价值。

### 冬：靠近、重逢与坍缩

补拟：危机处理依赖「把两侧状态强制设为一致」的装置／仪式。救人不是错误，过度使用单一覆盖方案才是结构问题。重逢进度确实上升，但它测到的是覆盖趋同，不是安全或幸福。首轮缺少完整证据，玩家以为解法成功。

新增既有事件：林汐瞒着久世弦独自献灵，久世弦反对。献灵与强制覆盖的具体关系采用第22节补拟；不可擅自认定她因此永久死亡。冲突应让两人的保护欲和错误判断都可理解。

### 春：另一视角、重新选择与共存

二周目不是同一角色重打，而是切换到林汐所在的A正螺旋进行游玩。可探索对象、古书问题、刀的时间操作和人物关系均从A侧成立；必要时通过残响看到B侧结果，但不随意切回久世弦替她完成决策。A→B→A的证据闭合，推翻普通过去／未来解释。

Boss不记得玩家，人物与事件却因新的行动改变。最终目标从重逢转为建立不消灭差异的联系；螺旋上升。结尾能否物理团聚保留问卷选择，不擅自取消或保证相见。


## 13. 世界事件表与伏笔账本

### 13.1 世界内部顺序

| 编号 | 事件 | 地点／人物 | 结果与状态 |
|---|---|---|---|
| E00 | 原初世界完整，双方均存在 | 镜湖／久世弦、林汐 | 继承；夏相识、秋在一起与灾害的相对年代待核，不强行绑定 |
| E01 | 灵矿与时间结构异常共振 | 镜湖深层 | 第一次灾害；最初触发者待缺失来源 |
| E02 | 正反双侧形成并发展 | A林汐／B久世弦 | 古代、现代文明表现；不是单向年代轴 |
| E03 | 双方发现对方残响 | 湖岸、遗迹、研究区 | 把活人误认为历史人物 |
| E03a | 镜湖号M-07进入17分钟循环 | 镜湖隧道／林舟与乘客 | 主篇前瞻事件；火车保存一段未完成因果 |
| E03b | 林舟带科研资料逃出循环 | 旧铁路至镜湖区 | 完成交接后死亡或被现实抹除；资料成为主篇开场证据 |
| E04 | 潜行公式稳定，有限跨侧行动成立 | 成对节点 | 信息成为另一侧历史 |
| E05 | 救人、破障、协作累积 | 核心地点 | 善意有效；强制覆盖关系也累积（补拟） |
| E06 | 现实不一致扩大 | 地图、照片、亲友 | 历史重叠、记忆冲突、事件重复 |
| E06a | 冬篇林汐独自献灵，绕过久世弦 | 林汐／久世弦 | 新文件既有事件；具体仪式、代价、与E07的间隔补拟 |
| E07 | 重逢与强制统一 | 零相点 | 首轮Bad End，闭环完成 |
| E08 | 另一视角重新调查 | 林汐为主 | 回收B影响A的反证与两侧完整生活 |
| E09 | 保留联系、切断覆盖 | 双主角／灵矿网络 | 新操作解决结构，而非取消善意 |
| E10 | 双侧稳定共存 | 神圣时间线 | 开启此前未发生的未来 |

此表是编剧索引；闭环中的E03～E07并非可寻找唯一先后起点的普通线性链。不要把章节时间戳当成真实绝对年代。

## 14. 玩家体验时间线

**补拟预算，完整路线约12～13小时。**可操作验证前置；替代旧版40分钟恋爱开场和2～3小时才首次因果回报。

| 游玩时间 | 重点 | 主要操作与信息 |
|---|---|---|
| 00:00～00:10 | 林舟最后的交接 | 接收M-07科研资料、见证其崩解，形成第一问题 |
| 00:10～00:20 | 片头与回到夏篇 | 久世弦／林汐相识，香包与生活细节进入 |
| 00:20～00:45 | 初次异常闭环 | 手机／古书、基础枪刀、一次改变验证；形成垂直切片 |
| 00:45～02:00 | 证明对方存在 | 三层反馈初步出现，C01简单协作 |
| 02:00～04:00 | 调查与帮助 | 医疗、学校、生活区；NPC与记录变化 |
| 04:00～06:00 | 掌控与深层代价 | C02高阶协作；救人选择、回报延迟加深 |
| 06:00～08:00 | 异常聚合 | 进度喜报、记忆冲突、云顶反证 |
| 08:00～09:00 | 重逢与Bad End | 执行错误统一方案，回收早期警示 |
| 09:00～11:00 | 第二轮／另一视角 | 林汐调查首轮缺失环节，跳过已知重复操作 |
| 11:00～12:30 | 真相与新解法 | C03最终协作，切断覆盖而保留联系 |
| 12:30～13:00 | 关系与未来 | 收束香包、家庭与双侧生活；具体相见形式待答 |

二周目必须有A侧独占地图状态、人物、问题、刀术操作与决策，不增加敌人血量充时长。剧情内连续进入A线是现行方案；完成后可回顾章节。一周目看见的B侧结果，在二周目成为林汐将要制造或拒绝制造的历史。


## 15. 前十分钟与四十五分钟切片

### 15.1 主篇开场可执行草案

| 时间 | 玩家看到／做到 | 当下疑问 | 后续回收 |
|---|---|---|---|
| 0～2分钟 | 雨夜旧铁路出口，林舟从本不存在的检修门跌出；列车声在身后重复 | 他从哪里出来？ | DLC的最后画面与主篇首镜互相衔接 |
| 2～4分钟 | 玩家协助他保持清醒；他拒绝解释全部乘客，只要求把防水资料盒交给第三研究所 | 为什么资料比救他更重要？ | 普通人的主动选择，不把他当投递工具 |
| 4～6分钟 | 资料盒内有M-07信号图、灵矿粉末、17分钟重复记录和一页缺失名单 | 已正常抵达的列车为何留下循环数据？ | F12、F13与灵矿共振研究起点 |
| 6～8分钟 | 林舟的伤口、衣物水迹和证件照片开始出现不同版本；他说出最后一句警告 | 是死亡、改写，还是现实拒绝他？ | 他把自己作为资料离开循环的代价推迟到此刻 |
| 8～10分钟 | 完成交接后林舟死亡并从大部分记录中消失，只有资料盒与维修本保留；片名出现 | 为什么物件能留下、人却不能？ | DLC悲剧落点、主篇第一问题、香包因果锚的前置对照 |

开场使者确定为DLC主角林舟。悲剧不是「跳出循环立刻无意义死亡」：他确实改变了世界，将循环内无法出现于现实的资料带给主篇；代价是自身失去被现实稳定记录的因果位置。主篇确认他完成交接后死亡，部分档案随即把他改写为「不存在的检修员」。维修本与资料盒因为携带灵矿残留而幸存，形成香包机制的先行案例。

### 15.2 切片与首90分钟

- 10～20分钟：回到夏篇，建立男女主初见、香包与镜湖的正常生活；把林舟资料作为未来悬念，不立即解释。
- 20～30分钟：玩家提出假设，手机照片与古书拓印对应，跨侧改变可验证。
- 30～40分钟：一个单侧谜题战，另一侧先前留下的条件决定可行解；不占正式三场协作配额。
- 40～45分钟：用更早的照片回看现在，发现自己制造了第一条线索；留下通向湖心的具体问题。
- 45～60分钟：医疗或生活区给半小时级回报；家书、回忆或仍在场的亲友建立人物生活，不让已死亡的久世父母无解释复活。
- 60～90分钟：准备湖心协作；第一场正式协作在1～2小时范围内，按实测调整。

验收：玩家能说出自己改变了什么、为什么换侧、枪刀各难在哪里、下一步想验证什么。看不懂时先修证据和反馈，不堆术语说明。
