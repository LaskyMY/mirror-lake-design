## 17. 制作约束与参考保留

12地点、两种文明表现、季节和因果状态复用；新增状态必须关联可观察变化。灰港、冥河／冥窟先做少量关键子场景，避免增加名称就扩大资产量。优先角色立绘、UI、音乐、关键CG、Boss反馈；最终视角待原型。

| 参考 | 取用方向 |
|---|---|
| 命运石之门 | 强事件钩子、执念、前期细节后期回收 |
| P5R | 人物动作进入UI、时间地点提示、生活与决策连贯 |
| Outer Wilds | 知识成为进度 |
| In Stars and Time | 循环与人物关系 |
| Slay the Princess | 少场景因选择与认知产生新含义 |
| 1000xRESIST | 强叙事、视角变化、场景复用 |
| Undertale | 战斗规则参与角色与选择，战斗不总是默认答案 |
| Titan Souls／Hotline Miami | 短战斗、明确读招、成功操作的反馈 |
| 弹丸论破／Golden Idol／Chants of Sennaar | 问题、证据、推理与信息拼图 |
| Death’s Door／Animal Well／MiSide | 简化动作、小地图秘密密度、场景吸引力 |
| REPLACED／33号远征队 | 演出与战斗包装方向，不承诺其资产量 |
| Slay the Spire | 保留为曾讨论过的对照，不采用卡牌核心 |

以上为创作参考，不包含本轮实时市场评价或销量论证。旧讨论中的Steam比例不是现行设计依据。

制作优先级：第一闭环→第一协作Boss→一次可重访人物变化→两侧状态保存→第二视角。状态组合以事件依赖表管理，避免每次选择复制整张地图或整章剧情。

| 开场死者身份待选 | 确定为火车DLC主角林舟；逃出循环、交付资料后死亡／被记录抹除 |

仍待创作决定：最初灾害根因、夏秋关系与分裂年代的精确对应、True End相见形式、父母视觉细节、献灵最终代价。它们是后续问卷与创作任务，不再作为资料接收缺口。火车DLC的完整工作方案见第23节。

设计自检：改写须有证据；初期善意须有真实收益；风险可回看；第二轮须有新信息；假UI不能破坏系统可信度；人物不能被剧情便利地消除；重要结果必须由玩家操作兑现。
