《镜湖残响》 Mirror Lake Echo
Project Overview v1.0
项目基本信息
中文名：《镜湖残响》
英文名：Mirror Lake Echo

类型：
- 剧情驱动冒险游戏
- 科幻悬疑视觉小说
- 双时间线探索 RPG
- 解谜 / 叙事探索
一句话概念
当一个完整世界因为未知异常分裂成两条相反旋转的时间螺旋，
两个身处不同时间侧的人，以为自己正在寻找对方留下的遗迹，
却发现他们一直在同时书写彼此的历史。
核心主题
主主题：存在与理解。

核心命题：
两个世界都不是错误答案，只是不完整的答案。

莫比乌斯环代表：
无法理解彼此，所以不断重复。

螺旋代表：
理解彼此后，在重复中获得成长。
世界观核心
原初世界线（Origin Timeline）

最初世界只有一条完整时间线：
过去 → 现在 → 未来

包含：
- 久世弦
- 林汐
- 镜湖
- 两个文明体系
第一次相位灾害
镜湖区域发生未知异常。

完整时间结构产生变化。

世界产生两个稳定解：
- 正螺旋时间线
- 反螺旋时间线
双螺旋时间结构
两个时间线不是平行宇宙，也不是简单过去未来。

它们是同一个世界的两个演化方向。

正螺旋：
保存、记忆、历史。

反螺旋：
变化、探索、未来。
时间线设定
A时间线（正螺旋）
核心人物：林汐
状态：现代 / 当下
久世弦成为遗迹中的残响。

B时间线（反螺旋）
核心人物：久世弦
状态：现代 / 当下
林汐成为遗迹中的残响。
镜湖与灵矿
镜湖：
不是时间机器，而是两个时间螺旋距离最近的位置。

灵矿：
不是能源，也不是魔法石。
是一种特殊的信息晶体，用于保存时间结构中的残留信息并放大共振。
残响（Echo）
残响不是灵魂。

它是被覆盖时间线留下的信息残留。

包括：
- 声音
- 文字
- 物品
- 行为痕迹
- 情感记录
潜行公式（Sneaking Formula）
两个时间螺旋之间的信息共振现象。

不是穿越。
不是通讯。

一个人的行动，会成为另一个世界的遗迹。
剧情结构
第一幕：镜湖的夏天
主题：相遇。

第二幕：双螺旋调查
主题：理解。

第三幕：莫比乌斯崩坏
主题：错误答案。

第四幕：螺旋上升
主题：真正的理解。
结局
Bad End：
强行融合两个世界，世界回到循环。

True End：
两个螺旋不再互相吞噬。
过去拥有未来，未来保存过去，形成神圣时间线。
核心玩法
- 双螺旋时间线：双主角章节切换
- 残响：收集世界碎片
- 潜行公式：留下信息影响另一时间线
- 镜湖：开启共振区域

最终目标：
从莫比乌斯环走向螺旋上升。
