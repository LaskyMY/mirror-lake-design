# 《镜湖号：未抵达者》DLC设计

摘自《镜湖残响》现行设计总纲 v0.5。

## 23. 前瞻DLC 镜湖号 未抵达者

### 23.1 项目定位

独立体验约55～60分钟，一列火车、五个可探索区域、六名核心人物、17分钟循环。它既是主游戏前瞻Demo，也是主篇开场人物林舟的完整故事。玩家先在DLC中经历他的选择，再在主篇开场看见选择的代价。

一句话：**铁路检修员林舟被困在镜湖隧道前的17分钟残响中；他不能救回早已死亡的乘客，只能让被掩埋的事故重新拥有真实记录，并把循环内的科研证据带给未来。**

暂定标题：《镜湖号：未抵达者》。旧提案《Loop 07》《最后一班镜湖号》保留为章节名或宣传副标题。列车暂定M-07，旧提案K072作为历史来源，不同时使用两个正式编号。

### 23.2 与主世界统一的循环逻辑

火车没有在现实轨道上无限绕圈。原事故发生后，列车、乘客行为和灵矿样本被保存为一段未完成因果；循环是残响空间，不是完整时间旅行。

- 火车之外没有连续的「现在」。跳车会进入无记录区，声音、动作和身体逐渐冻结，随后被最近的有效记录拉回车内。
- 紧急制动能够改变本轮事件顺序，却无法把残响接回现实轨道。列车减速后，下一个可见景物仍会折回隧道入口。
- 驾驶室可以操作，但轨道终点未被残响保存；强行前进只会更早触发归零。
- 死亡、坠车、被杀和时间耗尽都从隧道入口恢复。玩家保留认知，物件默认复位；维修记录中的灵矿粉尘能保存少量跨轮信息。
- 离开方法是补全真实因果：确认第17名在场者、还原事故与封口、将可验证证据带出。循环不要求牺牲「命定该死的人」。

最后一条修正旧候选「让真正该死亡的人死亡」。本世界主题不设天命死亡名单。乘客已经在原事故中死亡，DLC的伦理选择是承认事实、保存其选择与追究责任，不能靠重新献祭一人获得出口。

### 23.3 林舟

- 27岁，镜湖镇铁路局临时信号检修员，外地调入；事故列车上没有登记的随车检修人员，因此他就是名单外的第17人。
- 普通、疲惫、黑色短发，旧铁路工作服；维修记录本、快没水的钢笔、绝缘工具包。
- 理性、负责、怀疑怪力乱神、有点嘴硬。他愿意查清楚，但不以英雄自居。
- 开始相信「火车会坏，信号会错，机器会骗人，但时间不会」；结尾承认记录也会撒谎，仍选择留下可验证的记录。
- 他不是久世弦或林汐的替代品。DLC没有灵矿枪刀；核心操作是观察、定时干预、维修、对话、交换物件与记录矛盾。
- 主篇价值：他带出的信号图、样本监测纸带和维修本，是现代研究第一次获得「循环内部连续数据」。他不知道双螺旋全貌，无法提前解释主篇谜底。

### 23.4 原事故

M-07夜间列车驶向镜湖镇，行李车厢秘密运输一只送往第三山体研究所的灵矿样本箱。运输单把它伪装成地质设备。列车接近湖底隧道时，信号系统产生17分钟重复；工作人员仍被要求放行。隧道渗水与电力故障叠加，列车在黑暗中失控，所有在场者死亡。

官方记录后来被改为「列车正常抵达、无人伤亡」，铁路随即以维护为由关闭。异常并非由乘客的小选择凭空制造；样本共振、错误放行和事故构成直接原因。乘客未完成的电话、交接、道歉和证词决定残响保存了什么，使循环迟迟无法结束。

责任人的身份不在一小时DLC中完全揭晓。玩家能确认有人伪造运输与信号记录，不能确认其是个人、研究所部门或更高层。这样为主篇保留封口调查空间，并可与久世父母矿难线互相映照。

### 23.5 五个区域

| 区域 | 常规用途 | 核心谜题 | 状态变化 |
|---|---|---|---|
| 驾驶室 | 车速、信号、广播 | 为什么司机收到相互矛盾的放行指令 | 解锁纸带记录与手动广播 |
| 商务车厢 | 运输人员与少数乘客 | 谁在押送伪装的灵矿样本 | 公文包、座位与证件交换 |
| 普通车厢 | 乘客主体 | 第17人的座位为何不存在 | 人数、车票、合影随干预变化 |
| 餐车 | 人物交汇与物件交换 | 如何让六人的信息在同一轮连起来 | 停电前后的座位和对话链变化 |
| 行李车厢／连接处 | 样本箱、制动线路、工具 | 样本共振如何触发循环与出口 | 水位、箱体封条、检修门开启 |

厕所是普通车厢与餐车之间的小空间，用于藏匿、洗去纸条字迹和观察窗外重复，不作为第六张主地图。

### 23.6 六名核心人物

| 人物 | 身份与表面行为 | 隐藏信息 | 玩家干预与作用 |
|---|---|---|---|
| 林舟 | 未登记检修员；检查信号与车门 | 他就是名单缺失的第17人，先前循环的笔迹均属于他 | 用记录本积累知识，最后主动把自己写入真实名单 |
| 周岚 | 列车长；反复清点16张票 | 接到「不要登记临时检修员」的电话，害怕承担责任 | 取得她的工作章，才能让修正名单成为有效证据 |
| 陈默 | 司机；每轮第9分钟离开操作台片刻 | 收到纸面停车令与无线放行令；保存原始信号纸带 | 提前提醒可避免离席，取得连续17分钟数据 |
| 许禾 | 15岁女孩；寻找遗失车票 | 相机误拍到样本箱和林舟，却以为只是模糊废片 | 找回车票后她不再乱跑；照片成为第17人在场证明 |
| 贺庭 | 地质研究所运输员；守着公文包 | 知道货物是灵矿，签署过伪装运输单；想在到站前匿名举报 | 让未发出的举报与样本编号对应，锁定封口证据 |
| 孙桂枝 | 退休矿区护士；反复望向山体 | 认得样本封条与旧矿难伤员记录，知道同类晶体曾被运出雪山 | 她的证词连接DLC与玄岳矿难，但不直接说出全部主线真相 |

人物的未完成愿望不是六条独立支线。周岚的登记、许禾的照片、陈默的纸带、贺庭的运输单、孙桂枝的识别共同证明林舟与样本真实存在；任何单一证据都能被官方解释掉。

### 23.7 三层循环与玩家进度

循环不是严格只允许三次。正常完成约4～6轮；「三层」表示认知阶段，可通过已知信息跳过重复流程。

| 阶段 | 建议时长 | 玩家目标 | 关键发现 |
|---|---:|---|---|
| 机械循环 | 0～15分钟 | 修门、刹车、信号，尝试下车 | 故障会复位；车外没有连续现在；记录本留下压痕 |
| 人物循环 | 15～38分钟 | 改变乘客路线，让证据在一轮相遇 | 16张票却有17人；样本箱、放行令、照片彼此关联 |
| 记忆循环 | 38～53分钟 | 识别旧笔迹、补全名单、决定保存什么 | 以前的林舟已失败多次；火车是原事故残响，无法救回亡者 |
| 最后驶离 | 53～60分钟 | 完成证据链，将资料盒推出残响 | 乘客完成未说完的行动，林舟带资料进入现实并承担代价 |

重复优化：已成功完成的长对话可用一句验证；发现时刻表后显示事件节点；第三阶段允许从隧道入口直接布置已知物件。不能强迫玩家逐字重听前两轮。

|---:|---|---|---|

| 14:30 | 许禾发现车票丢失 | 小型人物事件 | 提前归还后，她会拍下行李车连接处 |
| 12:00 | 贺庭尝试发送举报 | 手机没有信号 | 借用列车维护端口保存草稿与样本编号 |
| 10:00 | 周岚清点车票 | 确认16名乘客 | 盖章补录林舟，制造第17人正式记录 |
| 08:00 | 陈默收到无线放行 | 正常调度 | 用纸面停车令质问，保留矛盾纸带 |

### 23.9 核心谜题与结局

最终解法需要四类独立证据：有效名单证明第17人，照片证明林舟与样本在场，纸带证明信号重复和矛盾指令，运输单／证词证明样本来源。玩家还需在行李厢用维修工具将样本箱外壳接到车载记录端口，把17分钟监测数据写入防水资料盒。

最后一次进入隧道前，其他五人恢复对事故的片段认知。他们不突然变成全知幽灵，只完成一直未完成的动作：盖章、保留纸带、交出照片、署名举报、写下证词。列车第一次抵达残响中的「终点」，乘客随记录关闭而消失。

林舟发现只有名单中的存在才能随列车留在封闭记录里；他把自己的名字留在修正名单上，却借样本共振把资料盒和自己短暂推出循环。这个漏洞让他进入主篇现实，也使他的身体没有稳定历史支撑。

**正史结局：未抵达者。**林舟步行抵达旧铁路出口，把资料交给主篇接收者；随后死亡，身份从普通数据库与大部分人的记忆中被抹去。修正名单、维修本和资料盒保留他的名字。DLC结束在他跨出检修门；主篇从门外接续，展示完整悲剧。

可选坏结局：继续修车、独自跳车、烧毁名单、封存样本、试图救所有残响人物。它们都提供一条新线索后复位，不用长死亡动画惩罚实验。暂不设置一个能让林舟无代价生还的隐藏结局，避免削弱主篇开场。

### 23.10 与主篇的信息边界

DLC明确展示：残响能保存未完成因果；灵矿会放大并携带记录；多份相互独立的证据可以对抗改写；离开循环需要完成真实因果而非杀死指定人物。

DLC不揭示：正反双螺旋全貌、林汐献灵、久世父母事故真凶、守环者身份、神圣时间线和True End方法。林舟带出的数据只让第三研究所能够观测异常，为久世弦后来的枪械模块与研究路线提供技术前提。

主篇可在第三研究所、旧铁路和灰港三处回收林舟：信号图被引用却删去作者；废弃检修柜中有同款钢笔；灰港运输表出现第17个签名。二周目A线可以看到与列车记录对应的古代车辙／运矿队残响，证明火车事件也有另一侧原因，但不把DLC重新打一遍。

### 23.11 一小时制作范围

- 五个复用空间状态：正常、停电、进水／共振；不制作车外开放地图。
- 六个人物，每人一套基础立绘／模型、三种关键表情或姿态；路人仅作背景剪影与名单数字。
- 核心系统：17分钟时序、知识解锁、物件交互、对话快捷验证、记录本、四类证据组合、五种复位结局。
- 不加入枪刀战斗、背包数值、随机谜题或大量分支结局。危险通过赶时间、断电、进水和人物位置产生。
- 首次通关目标55～60分钟；熟练真结局约20分钟；任何单轮最多17分钟，前两轮可因失败提前复位。

### 23.12 DLC后续制作顺序

先做一节普通车厢、林舟／周岚／许禾三人和5分钟微循环，验证重复对话与知识跳过；再加入驾驶室纸带、行李厢样本及完整17分钟时序；最后补餐车、孙桂枝、贺庭和主篇衔接演出。垂直切片必须让玩家发现「16张票、17个人」并主动利用一次跨轮记录。
